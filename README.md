# 自己上网学东西的 AI Agent

一个跑在本地的自主研究 agent。没人给它题目的时候，它自己决定学什么：
自己挑方向 → 上网搜论文 → 抓全文 → 逐句读 → 判断学到没有 → 写成人能看的东西。
攒了几周之后，你可以直接问它"你学过什么关于 X 的"，它把库里的知识组织成一段话，
每条结论挂 arXiv 链接和页码。

本地模型（Ollama + qwen3:8b），不需要联网调用任何付费 API。

## 它跟问答助手有什么区别

| | 问答助手 | 这个 |
|---|---|---|
| 谁定方向 | 你问，它答 | **它自己定** |
| 学没学到 | 无所谓 | 它自己判断，判断不了就不入库 |
| 产出 | 一段回答 | 每日发现 / 追踪周报 / 术语表 / 知识库 |
| 你不在的时候 | 什么都不发生 | 定时任务自己跑，跑完推手机 |

## 快速开始

```bash
pip install -r requirements.txt

# 装个本地模型（8G 内存以上建议 8b，不够就换更小的）
ollama pull qwen3:8b

python explore.py                      # 它自己逛 3 个方向，出一份《每日发现》
python tracks.py                       # 看追踪线：几条线、各追到第几周
python ask.py "表面码是怎么纠正错误的"   # 问知识库学过的东西
```

Windows 上双击 `自己去学.bat` 等于 `python explore.py`
（.bat 会自动在 PATH 里找 python，找不到再退回常见安装路径）。

## 它在做什么

一次运行分两半，这是"纵"和"横"：

**追踪线（纵）**——同一个话题连着追几周。每期扫 20~30 篇摘要算词频
（趋势的原料），只深读 1~2 篇（你看的内容）。周报里多一段
「跟前几周比，什么变了」：哪些词在涨、哪些在掉、这条线卡在哪。
追满 8 周自动收线。**同一条线至少隔 3 天才推进**——arXiv 一天新增不了几篇，
天天追等于天天比同一批论文，词频不会动，趋势也就无从谈起。

**自由探索（横）**——12 个学科轮换，撞上有价值的话题就立成新线。

| `explore.py` | 主流程：追线 + 自由探索 + 写每日发现 |

| `glossary.py` | 术语解析：模型挑词讲白话，攒成跨期术语表 |

| `ask.py` | 问答入口：问知识库学过什么 |
| `survey.py` | 成果报告：五段式综述 |
| `nightly.py` | 无人值守调度：锁、等 ollama、防睡眠、推送 |
| `notify.py` | 推送：ntfy / pushplus / Server酱 / 邮件 |
| `serve.py` | 把产出挂成网页，手机能看 |

## 三条一直在守的规矩

这个项目踩过的最大的坑，是**模型会编**。编一个不存在的术语、编一句没在
论文里出现过的话、编一个 arXiv 编号。三条规矩都是为这个设的：

1. **模型报编号，程序取原文。** 论文要点由模型报告句子编号，引文由程序
   从原文里取。问答里它报用了哪几条事实，链接和页码由程序按编号列。
   编号对不上是看得见的失败，比编一个链接好。
2. **词必须真的在原文里。** 模型挑术语，但这个词必须能在原文中找到，
   找不到直接丢弃。
3. **宁空不编。** 几篇论文之间看不出关系，就写"看不出明确关系"；
    arXiv 限流了，就说"判断不了"，不说"这个方向追不动"。

## 已知限制

- **8b 的判断力是天花板。** 它决定学什么、判断学没学到，都是 8b 在做。
  质量上限就在这，换大模型是唯一的提升途径（`survey.py` 里改 `MODEL`）。
- **趋势需要真实的时间间隔。** 一天跑两次，检索到的是同一批论文，
  词频一动不动。这是方法在正常工作，不是坏了。
- **arXiv 限流。** 请求要隔 3 秒，连续跑大轮次会撞 429。
- **不传文献库。** 下载的 PDF 在 `文献库/`，被 gitignore 掉了，
  首次运行会自己重新下。
