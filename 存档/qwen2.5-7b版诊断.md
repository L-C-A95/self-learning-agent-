## 一、一句话结论

**换模型没有解决问题，只是把问题的形状换了一种。**

灾难性的"反爬页当证据"没有再出现（因为这次没踩到反爬页，不是因为模型变好了）。但换成了另一种更难发现的问题：**每条声明都像模像样，主语和术语却悄悄被改过。** 而你的检验装置完全没拦住——因为它校验的东西，在逻辑上必然成立。

## 二、决定性证据：grounding 校验的对象错了

看 Evidence 第 20 条：

```
claim： AlphaGo Zero使用蒙特卡洛政策梯度进行策略网络训练。
quote： Train Policy Network Using Policy Gradient Reinforcement learning of policy network
判定： [✓] grounded
```

**claim 是中文，quote 是英文。中文句子不可能逐字出现在英文原文里。**

所以这个 ✓ 绝对不可能是"claim 是原文的子串"。只有一种解释能同时对上：

> **它校验的是"我贴的那句引文确实在这张网页里"，而不是"我写的那句结论被这句引文支持"。**

这两件事完全不同。前者几乎永远成立——因为引文本来就是从网页复制的。**它是个恒真命题。**

这一个机制，能同时解释你七份报告的全部怪现象：

| 现象 | 用"校验引文是否在网页里"解释 |
|---|---|
| `， 。` → "系统使用逗号和句号" | 引文在网页里 ✓ |
| `视频` → "视频功能可用" | 引文在网页里 ✓ |
| `环境异常，` → 成为分析前提 | 引文在网页里 ✓ |
| `AlphaGo` → 写成 `AlphaGo Zero` | 引文在网页里 ✓，谁改的主语没人管 |
| 90/90、81/81、159/159、24/24、93/93 全满分 | 因为它从设计上就不会失败 |

**这就是为什么"100% grounded"永远等于"什么都没验证"。** 它比 3 倍膨胀更严重——3 倍只是重复计数，这个是让整套检验机制失去意义。

修复只需要一句话：**校验方向反过来。** 不是问"引文是否在网页里"，而是问"结论是否只包含引文里的信息"。

## 四、这份报告的六个具体问题

### 1. 主题是一半拼出来的
标题写"AI alignment reinforcement learning"。但 31 条声明里：

| 来源 | 条数 | 性质 |
|---|---|---|
| CSDN《AI对齐关键点理解》 | 8 | 二手科普博客，非学术 |
| arxiv **搜索结果页**（作者 Lindström） | 6 | 相关，但来源不可引用 |
| NVIDIA PrefixRL 技术博客 | 5 | **完全跑题**（用 RL 设计芯片电路） |
| CSDN《AlphaGo 实例》 | 7 | **跑题**（RL 但与对齐无关）+ 二手 |
| arXiv 2609.29001 礼貌判断 | 5 | 相关，真论文 |

**真正来自学术论文的证据只有 5 条，占 16%。跑题内容 12 条，占 39%。**

摘要第一句就把三件事硬拼成一句因果："AI alignment and reinforcement learning are crucial for ensuring that AGI are safe..."——**这是检索按关键词拼接的产物，不是论证。**

### 2. 把 arxiv 搜索结果页当成了论文
src[2] = `arxiv.org/search/cs?query=Lindström,+A+D`

这是个**作者检索结果页**。它会随检索结果变化，今天有明天可能没有。引用它等于引用不了。而且它连"这是哪篇论文"都说不清——你按这个链接点进去，看到的是一列搜索结果。

### 3. 主语被篡改（7B 最典型的手病）
```
claim： AlphaGo Zero通过行为克隆初始化策略网络。
quote： AlphaGo Initialize Policy Network by Behavior Cloning
```
原文写的是 **AlphaGo**，claim 写成了 **AlphaGo Zero**。这两件事在 AlphaGo 系列里是不同代际的技术路线，不是笔误。

### 4. 术语被脑补
```
claim： AlphaGo Zero使用【蒙特卡洛】政策梯度进行策略网络训练。
quote： Train Policy Network Using Policy Gradient ...
```
原文只有 "Policy Gradient"，**没有"蒙特卡洛"**。这是模型从常识里补的。

### 5. 把标题当结论
```
claim： 强化学习中的马尔可夫决策过程（MDP）是其核心概念之一。
quote： 马尔可夫决策过程
```
原文只有这六个字的**小标题**。claim 从标题推出了一个论断。

### 6. 中英混杂失控
正文是英文，Evidence 20–26、51–57、82–88 却是中文——因为源是 CSDN 中文博客，模型直接把中文原句当 claim 留着。**一份报告两种语言，中间没有任何转换或标注。**

## 五、7B 模型到底差在哪（这条最重要）

不是"7B 更笨"，是**7B 会把"概括"当成"引用"**。

大模型倾向于照抄原文（哪怕抄得生硬）；小模型倾向于"理解后用自己话说"，于是每一条都变成了**改写**。而改写必然带来主语漂移、术语补充、范围扩大——这些恰恰是最难被发现的错误，因为它们读起来比原文还通顺。

所以给你的判断：

- **7B 不是不能用，是不能让它"总结"。**
- 它的任务必须从「总结 → 结论」降级为「给定段落 → 摘出原句」，一步都不许自己走。

## 六、该修什么（按顺序，全部与模型无关）

### 第一优先：把校验方向反过来（一句话的改动）

```python
# 现在大概是（恒真）：
assert quote in page_text

# 应该是：
assert claim_info ⊆ quote_info
# 即：claim 里出现的所有专有名词、数字、因果关系，都必须在 quote 里出现
```

最省事的近似实现——**专有名词与数字白名单校验**：

```python
def check(claim, quote):
    for token in extract_entities(claim):   # 人名/模型名/数字/英文缩写
        if token not in quote:
            return FAIL(f"claim 含 quote 中不存在的信息：{token}")
```

用这一条回归测试，能自动抓出第 3、4、5 节里的三条（AlphaGo Zero、蒙特卡洛、MDP），一条不漏。**这是投入产出最高的一处改动，大概二十行。**

### 第二优先：3 倍循环（已确认与模型无关）

四份旧报告 + 这一份，五份全部精确 ×3。去看那段循环为什么跑三遍，别再怀疑模型了。

### 第三优先：来源准入（治跑题）

- 拒绝 `arxiv.org/search`、`blog.csdn.net`、搜索结果页、词典页作为来源
- 一份报告至少 **2 个学术来源**（arxiv abs/html、期刊页），否则降级或拒答
- 来源域名白名单：`arxiv.org/abs`、`arxiv.org/html`、`*.edu`、`*.ac.cn`、`*.nature.com` 等

### 第四优先：语言归一

源是中文就输出中文 claim + 中文 quote；源是英文就全英文。**不许跨语言改写**——跨语言改写是主语漂移的高发区，而且无法用字符串校验。

## 七、一个反直觉的建议

**不要把这次的问题归到模型头上，也不要急着换回去。**

你现在有两个变量同时在动：模型（7B / 大模型）和管道（校验、去重、引用）。同时动两个变量，你永远不知道是哪个起了作用。

建议的做法：

1. **固定 7B**，先把上面四条管道问题修掉，用这七份报告做回归集
2. 修完之后再跑一遍同样的 6 个问题
3. 如果 3 倍消失、悬空引用消失、跑题被拒——说明**管道才是主因，模型不是**
4. 到那时如果还想提升行文质量，再换大模型，才算干净的对照实验

**先修管道，再谈模型。** 否则你会一直在一个 31×3 的循环里换模型，每次都得到一份"看起来更好、其实一样错"的报告。
