# 产出

所有生成的东西都在这里，程序只会往这五个子目录写，不会再堆到根目录。

## 追踪周报

`explore.py` 每推进一条追踪线就写一份，文件名带「第N周」。
这跟「每日发现」不是一回事：每日发现是当天随手逛到的，追踪周报是**同一个话题
连着追几周**的对照——这周读的、跟前几周比哪个词在涨、这条线卡在哪。
要看趋势只能看这个，改天换一批话题是看不出趋势的。

## 每日发现

双击 `自己去学.bat` 生成。它自己挑学科、上网读论文，每次一份。
内容：逛了哪些方向、每篇论文一句话讲清做了什么、附原文句子和页码、
末尾列出"搜到但这次没读"的论文，方便下次接着看。

## 成果报告

给它一个明确主题时生成（`网络自主学习.bat`，或 `survey.py`）。
五段：知识点总结 / 横向对比 / 纵向演进 / 值得往哪走 / 没做到的。
每段都标了出处，判断和事实分开写。

## 夜间记录

无人值守那几轮（`手动跑一次研究.bat` / 每晚定时任务）留下的记录：
学到什么、哪些没学到、为什么、下一步建议。跑砸的时候也在这里，
是排查"它为什么没产出"的第一手材料。

## 问答记录

双击 `ask.bat` 产生：你问一句，它把知识库里学过的东西用人话答出来。

和"成果报告"的区别是——成果报告是它自己学完写的综述；这个是**你问它答**，
每条结论后面挂着 arXiv 链接和页码，能翻回原文核验。

```cmd
ask.bat 表面码是怎么纠正错误的      :: 带问题，直接问
ask.bat                             :: 不带参数，进交互模式连着问
ask.bat --dry 共识                  :: 只看会命中什么，不调模型
```

现在库里 264 条事实、100 个术语。同一个词有几种写法的（自我纠正/自我修正/
自纠正循环），检索时会自动扩展同义词，不会因为用词不同就召不回。
